# 工作记录 WorkLog

**作者：At0m**

>  离线可用的本地工作记录工具：记工作、管资料、搜全文、看日历、导周报。
> A fully offline, zero-dependency work journal: notes, files, full-text search, calendar & weekly exports. Python 3 standard library only.

## 简介

一个跑在本机的小工具，帮你把每天做过的工作记下来：每条记录可以挂一个文件夹收集相关资料（截图、表格、文档随便放），支持全局搜索，能按周/按年一键导出 txt 总结，还有月历视图和截止提醒，方便每周报工作和年底复盘。

**完全离线、零依赖**：只用 Python 3 自带的标准库，不需要联网、不需要 pip 安装任何东西，拷过去就能跑。特别适配麒麟（Kylin）等国产离线办公环境（x86 / 飞腾 / 鲲鹏均可），Linux 和 macOS 也支持。

**数据永远是你自己的**：所有内容保存在普通文件夹里（Markdown + 文件），不用这个程序也能直接浏览、拷贝、备份，永远不会被"锁死"在软件里。

## 功能一览

- 📝 **工作记录**：标题、日期、类别（可自定义）、标签、正文；`Ctrl+S` 保存
- ✅ **完成状态**：每条记录可标记"已完成"，列表可一键"只看未完成"
- ⏰ **截止提醒**：给记录设截止日期，打开程序时顶部自动提醒超期/3 天内到期事项，月历里同步标色
- 📅 **月历视图**：开屏默认显示，一个格子一天；蓝底=当天做的工作，黄底=当天截止，红底=已超期未完成；点条目直接打开
- 📁 **资料收集**：每条记录一个独立文件夹，可拖拽/点按钮上传文件，也能一键在文件管理器中打开直接拖入
- 🔍 **全文搜索**：同时搜标题、正文、标签和资料文件名，命中高亮，支持类别/日期/完成状态组合筛选
- ⇩ **导出总结**：导出 本周 / 任意时间段 / 全年汇总 为 txt（一行一条：日期+标题+【类别】+该周期内追加的更新，带时间戳），自动在数据目录存档一份，方便每周报送和年度复盘；支持同标题去重
- ➕ **追加更新**：任务进展以带时间戳的更新形式追加，任务日期自动跟到最新；周导出只带出本周新加的内容，旧话不重复
- 🗑 **删除保护**：删除时可选"资料文件保留在磁盘"或"彻底删除"
- 🗂 **类别管理**：内置常用类别，可随意增删

## 快速开始

要求：Python 3.7+（麒麟 V10、主流 Linux、macOS 均自带，无需安装）

```bash
# 方式一：直接运行
python3 main.py

# 方式二：双击或运行启动脚本（Linux/macOS）
bash 启动工作记录.sh
```

启动后浏览器自动打开程序页面（默认 `http://127.0.0.1:8765`）；若没有自动打开，把终端里显示的地址手动输进浏览器即可。停止：在终端按 `Ctrl+C` 或直接关窗口。

## 数据存哪

默认自动放在系统「文档」目录下的 `工作记录` 文件夹（Linux 中文系统为 `~/文档/工作记录`，macOS 为 `~/Documents/工作记录`），每条记录一个文件夹：

```
工作记录/
├── 2026/
│   ├── 2026-10-20 周报编写/
│   │   ├── record.md        ← 记录内容（含日期/类别/标签/状态/截止，纯文本随时可读）
│   │   ├── 数据统计.xlsx     ← 这条工作的资料，直接放这里
│   │   └── 现场截图.png
│   └── 2026-10-18 检查材料整理/
│       └── ...
├── 导出/                     ← 导出的周/年总结自动存档在这里
└── index.db                  ← 程序的搜索索引（自动维护，无需理会）
```

## 配置

程序目录下的 `config.json`（首次修改配置后自动生成）：

```json
{
  "data_dir": "数据目录路径，可改成任意位置（如移动硬盘、网盘同步目录）",
  "categories": ["自定义类别列表"],
  "port": 8765
}
```

## 平台说明

| 平台 | 支持情况 |
|------|----------|
| 银河麒麟 V10（x86 / 飞腾 / 鲲鹏） | ✅ 主要适配目标，离线零安装 |
| 其他 Linux 发行版 | ✅ 只要有 python3 即可 |
| macOS | ✅ 可用 |
| Windows | 未专门适配（`python3 main.py` 大部分功能可用，打开文件夹等个别功能失效） |

## 技术说明

- 后端：Python 3 标准库（`http.server` + `sqlite3`），单文件 `main.py`，无第三方依赖
- 前端：原生 HTML/CSS/JS，无框架、无 CDN，离线浏览器完全可用
- 搜索索引为 SQLite，记录内容实时镜像到各文件夹的 `record.md`
